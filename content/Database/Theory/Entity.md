# Entity 
엔터티(Entity) 는 사람, 장소, 물건, 사건, 개념 등 여러 개의 속성([[Attribute]])을 지닌 명사를 의미합니다. Database 에서는 주로 **테이블의 행을 엔터티**라고 부르고 있습니다. 

# Strong Entity
**엔터티 하나만으로 식별이 가능**한 엔터티를 강한 엔터티라고 할 수 있습니다.  예를 들어, 사람은 주민등록번호, 이름의 속성([[Attribute]])를 가진다면 한국에서 식별이 가능하기 때문에 강한 엔터티라고 구분지을 수 있습니다.

# Weak Entity 
**엔터티 하나만으로는 식별이 불가**능한 엔터티를 약한 엔터티라고 할 수 있습니다. 예를 들어, 좌석 번호를 가지고 있는 테이블은 반드시 버스 테이블과 결합되어야 식별이 가능해집니다.
