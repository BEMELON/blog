# Entity Relationship Diagram

ERD(Entity-Relationship Diagram)는 개체-관계 다이어그램으로, 데이터베이스 설계에서 개체(엔티티)와 그들 간의 관계를 시각적으로 표현하는 도구입니다. ERD는 데이터베이스의 구조와 관계를 이해하고 설계하는 데 도움을 주는 중요한 도구입니다.

## 논리 ERD (Logical ERD)

개념적인 수준에서 데이터베이스를 설계하는 단계입니다. **엔티티와 그들 간의 관계를 중심**으로 표현하게 됩니다. 해당 ERD는 실제 구현보다 비즈니스 요구사항을 적절히 반영하는 개념적인 데이터 모델을 만들기 위해 사용됩니다.

## 물리 ERD (Physical ERD)

논리 ERD를 기반으로 실제 데이터베이스 시스템에 맞게 변환하는 단계를 의미합니다. 데이터베이스 시스템에 맞는 **데이터 타입, 인덱스, 제약 조건 등을 정의**하게 됩니다.
